# Нарезка мемов на твоём компьютере

Программа находит на YouTube русские нарезки «мемы бравл старс», вырезает из каждой самый
пересматриваемый момент (по данным YouTube) и отправляет его боту. Бот публикует фрагмент
в канале как обычное видео с плеером и подписью «фрагмент из нарезки … (канал автора)».

На GitHub это сделать нельзя: YouTube не даёт скачивать видео с серверов. С твоего компьютера можно.

**Про права.** Нарезки принадлежат их авторам. Публикуя фрагменты, канал берёт ответственность на себя.
Автор указывается в каждом посте; если кто-то попросит убрать видео, удали пост.

## Установка (один раз, Windows)
1. Установи Python с https://www.python.org/downloads/ и при установке поставь галочку **Add python.exe to PATH**.
2. На странице репозитория нажми **Code → Download ZIP**, распакуй и открой папку `local`.
3. Запусти **setup.bat**: поставит yt-dlp и ffmpeg.
4. Скопируй `config.example.txt` в `config.txt` и заполни (подсказки внутри):
   - `BOT_TOKEN`: токен бота от @BotFather;
   - `GITHUB_TOKEN`: токен GitHub только для этого репозитория с правом **Contents: Read and write**.

## Запуск
- **run.bat**: сделать фрагменты сейчас. Каждый фрагмент придёт тебе в личку от бота, а потом выйдет в канале среди мемов.
- **schedule.bat**: запускать каждый день в 12:00 (если компьютер включён). Отчёт последнего запуска в `last_run.txt`.

Не понравился фрагмент: в боте «🤖 Автопосты» → 🗑.
